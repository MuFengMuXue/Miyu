# Miyu 0.7.0

子代理改成只在后台跑，派出去就能接着聊，跑完带着结论叫醒她；子代理有了自己的会话，终端和网页都能切进去看、接着聊，任务条是一棵树。daemon 重启不再打断正在做的事，新 daemon 起来自己接着跑。macOS（Apple Silicon）可以用 Homebrew 装了。网页有了英文界面。另外一大批缓存命中、终端卡顿和 QQ 群聊的修正。

一百多条改动的完整记录在[这儿](https://github.com/SHORiN-KiWATA/miyu-agent/blob/v0.7.0/docs/releases/0.7.0/changelog.md)。

## 新增

- **macOS（Apple Silicon）版**：`brew install shorin-kiwata/miyu/miyu`，要求 macOS 15 及以上。不带语音包。会话沙盒走系统的 `sandbox-exec`，只锁写、不锁读。
- **子代理的会话能切进去看、接着聊**：点时间线或任务条上子代理那一行切进它的会话，`/back` 一层层退，`/subagent` 列出派出过的子代理。任务条改成树，子代理那一行带实时的在做什么、词元和用时。
- **daemon 重启后接着跑被打断的回合**：换版本、崩溃、被杀都算；子代理、`/goal` 续轮、QQ 一起接。手动停掉的那一轮不接。
- **会话之间的 AI 可以互相发消息**：新工具 `send_to_other_running_session`，给你另一个开着的会话捎话，对方在跑就插进这一轮，闲着就起一轮去回。
- **只读模式**：空会话 Shift+Tab、非空会话 Tab 一键切换，开着时 AI 能读全盘、哪儿都写不了。
- **默认开启沙盒模式**：写只限项目目录或 `~/.miyu/home/<你>/workspace`，`/sandbox <路径>` 换地方。新装默认开，老机器升级后默认关。
- **网页英文界面**：跟「界面语言」走，选「自动」时看浏览器语言。
- **终端输入框暂存**（Ctrl+S）：打到一半先收起来，空着时再按一下取回。
- **footer 显示缓存断了几次**（`断N`），`/usage` 列出每一次的时间、重算量和原因。
- **回合跑着时 `/compact` 排队**，这一批工具跑完就压。
- **思考档位按会话**：`/effort` 只改当前会话，菜单第一项「跟随全局」。
- **输入框旁显示这一轮的用时**，回复末尾一行 `✻ 模型 · 处理了 … · 几点完成`。
- **方向键进任务条、在命令候选里挑**：↓ 进任务条，回车切过去；`/` 候选 ↑↓ 挑、Tab 补全。
- **正文边流边出**：没写完的行和没闭合的代码块流着时就露出来。
- **长会话往上翻得到开头**（终端和网页都按页补）。
- **网页一次删多个会话**；网页随 daemon 升级自动刷新。
- **QQ 群聊专属限流**：给单个群定「多少秒内最多回几轮」。
- **QQ 管控命令的回执 3 秒后自己撤回**（`/reset` 系与 `/stop`）。
- **打开终端界面时进入新会话还是最近会话**，可以在设置里选。

## 变更

- **子代理只在后台跑**：派出后这一轮当场收尾；一次性命令（`miyu "…"`、`miyu ask`、`stdio`）等子代理全部跑完再退出；QQ 里同一轮的几个子代理合成一份汇报。
- **MCP 服务器按会话常驻**，读服务器的使用说明；**服务器进程关进会话沙盒**，要写沙盒外的在服务器对话框里加「额外可写目录」。
- **QQ 同一个人的追问并进他正在跑的那一轮**，只回一条；别人的消息照常排队。
- **QQ 发图、发文件改后台传**，不再卡住她；传失败像后台任务汇报一样告诉她。
- **QQ 冷静机制重做**：只管插嘴，看最近说了多少话，停下十来分钟就恢复；设置里只剩「回复克制」一个开关。
- **QQ 长文转图**：`<br>` 与常见 HTML 标签照画；换栏不留大片空白；长宽跟内容走；mermaid 用正文字体、思维导图改树状。
- **同一轮里的多个只读工具一起跑**，按调用顺序交回。
- **过程收起的那一行按类写**：`Ran 3 commands · 2 edits · 4 tools · 1 thought · 1 err`，一律英文；点开的一段往下展开。
- **会话数据收进数据库**：待办、上键历史、思考档位进会话库，用量账本进 `state/usage.db`，终端启动与换会话更快；老文件升级时自动导入。
- **开发模式默认不带提示词**，想要在 `miyu config` 里自己写。
- **`/clear` 等同 `/reset`**，清屏改按 Ctrl+L。
- **技能改成插件**，并按人格放进资源目录（`share/miyu/personas/<人格>/skills/`），技能和它的脚本在功能表里只占一行。
- **对话会话不再裁剪最早的对话**，上下文满了一律交给压缩。
- 功能表改名、支持 `Ctrl+A`；Arch 专属工具不再默认出现在非 Arch 系统上。
- 设置界面里编辑已有项的表单去掉「保存」「返回」，按 Esc 退出、主菜单统一保存。

## 修复

- **缓存命中**：打断、插话、连续相同的工具调用、`/goal` 收尾之后的下一轮不再整段重算（大会话首请求命中 98.1% → 99.8%）；QQ 断线重连、轮数用完的最后一轮、会话中途改技能不再让缓存整段失效；直连 Anthropic / OpenAI 官方接口带上缓存参数。
- **终端卡顿**：思考几万词元不再越来越卡；长会话打断立刻停；空会话切模式一按就换；长回合的时间线不再错位；大厅和面板在不支持同步输出的终端上不闪。
- **长回复切走再切回不再只剩一半**；回合跑着时开面板正文不再停住；收缩行下面不再空出一大块。
- 上下文超长时先自动压缩再重试（这个兜底此前一直没生效）；429 按 Retry-After 等、额度用完直接换端点。
- 压缩不再把一段闲聊当成摘要存下，也不再丢掉命令输出。
- 打断的轮照实记账，Σ 不再掉回去；换会话后网页的「累计」换成这个会话的。
- 后台任务汇报不再偶尔丢掉，回合收尾那一刻才到的汇报另起一轮去回。
- 答过的提问重开终端不再又弹出来。
- 在 `/session` 里删会话不会再误删别的会话。
- AI 改文件不再把权限改成 0600、不再丢执行位、改软链改的是目标；补丁删文件进回收站；命令超时交回已有输出。
- 中转线（claude-code、codex、codebuddy、agy）的工具面与普通模型对上；`--tools`、`--no-tools`、`--no-memory` 在中转线上生效。
- 在 opencode 端点上用视觉分析不再整轮 422。
- mimo、sensenova 在工具调用之间回传思考。
- 运行中新加的模型保存即查得到上下文窗口、档位和价格。
- herdr 里一轮跑完侧栏不再一直「进行中」，通知改走系统通知。
- 知识库设置不再误报「未配置 Embedding」。
- 搜图去掉下载后的视觉审核，不再整批误判不安全。
- 小红书扫码登录二维码不再一直换；macOS 上小红书、知乎、闲鱼、酒店比价脚本可用，认得出系统 Chrome。
- 终端集成在 macOS 上可用（找得到 Homebrew 装的 miyu、`rg`、`chafa`，bash 写进 `~/.bash_profile`）。
- 少装了程序时报错说清缺的是哪个、怎么装。

## 移除

- 设置项：「重开 TUI 回放的轮数」「长图最大高度」、冷静机制的恢复时间 / 强度 / 倍率、搜图的「视觉模型审核」、知识库表单的「语义最低分」「Embedding 超时秒数」。配置文件里留着的旧值会被忽略。
- 技能：`Linux 游戏兼容性`、`抖音/TikTok 下载`（能力由同名脚本承担）。
- 子代理的浮层、网页卡片里的内层过程（改为切进子代理自己的会话看）。

## 升级注意

- 要 `miyu daemon restart`。开着的终端要重开，网页刷新一次（下次升级起网页会自己刷新）。
- 升级后每个会话的第一轮会整段重算一次缓存（技能目录挪出了工具说明）。
- **沙盒模式**：新装默认开；已经在用的机器升级后默认关，想要去「全局参数设置 → 默认开启沙盒模式」打开。
- **MCP 服务器进了会话沙盒**：要写沙盒外面的服务器（比如浏览器缓存），在服务器对话框里加「额外可写目录」，或把它的「沙盒」改成「不关」。
- 会话数据搬进数据库，老文件升级时自动导入、这一版先留着，回退到 0.6.2 照样能用。
- `/clear` 现在会清空会话；只想清屏按 Ctrl+L。
- 非 Arch 机器上 Arch 专属工具会自动关掉一次，需要的在「人格和功能」里勾回来。
- macOS 包没有签名，浏览器直接下载会被 Gatekeeper 拦，请用 Homebrew 安装。

## 下载与安装

附件是七个安装包：Linux x86_64 六个、macOS（Apple Silicon）一个。Linux 主包自带字体、语义模型、表情、脚本、默认知识库和许可证；语音是可选包，版本要和主包一致，已经装了语音的请在同一条命令里写上两个包。

| 系统 | 主包 | 可选语音包 |
| --- | --- | --- |
| Arch Linux | `miyu-0.7.0-1-x86_64.pkg.tar.zst` | `miyu-voice-0.7.0-1-x86_64.pkg.tar.zst` |
| Debian 13 / Ubuntu 24.04 LTS 及更新 / Linux Mint 22 | `miyu_0.7.0-1_amd64.deb` | `miyu-voice_0.7.0-1_amd64.deb` |
| Fedora 44 | `miyu-0.7.0-1.fc44.x86_64.rpm` | `miyu-voice-0.7.0-1.fc44.x86_64.rpm` |
| macOS 15+（Apple Silicon） | `miyu-0.7.0-1-aarch64-apple-darwin.tar.gz`（请用 Homebrew 装） | — |

```bash
# Arch Linux
sudo pacman -U ./miyu-0.7.0-1-x86_64.pkg.tar.zst

# Debian / Ubuntu / Linux Mint
sudo apt install ./miyu_0.7.0-1_amd64.deb

# Fedora 44
sudo dnf install ./miyu-0.7.0-1.fc44.x86_64.rpm

# macOS（Apple Silicon）
brew install shorin-kiwata/miyu/miyu
```

六个 Linux 包都在 Arch、Debian 13、Ubuntu 24.04、Ubuntu 26.04、Linux Mint 22.3、Fedora 44 的干净容器里装过一遍，macOS 包在 macOS 15 上解压验收并真装了一遍 Homebrew formula，每个都让她真回了一句话，47 项必需检查全过。Arch 也可以走 AUR：`miyu` / `miyu-voice` 是二进制包装，`miyu-git` 从源码构建。
